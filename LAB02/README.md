## LAB02 - Rock-Paper-Scissors Game

A console application where users play Rock-Paper-Scissors against the computer.

### How to Run

```bash
cd LAB02
npm install
npm start / npm run dev
```

### Game Rules
- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
